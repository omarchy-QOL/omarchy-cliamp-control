# Assets

## Preview and demo

`../preview.png` is the owner-supplied CLIamp screenshot used at the top of the
README and as the marketplace preview. The marketplace requires this image in
the repository root; the manifest does not have a preview-path field.

`published/cliamp-quake.mp4` is the owner's recording from 8 September 2026.
It shows alignment, resizing, and toggling with a separate input overlay.
The original file is preserved without re-encoding: H.264, 1920 x 1200, 60 fps,
65.717 seconds, 7,483,957 bytes, and no audio stream.

GitHub Pages serves the demo from the default branch, following Syncshell's
asset layout. `.nojekyll` keeps the files unchanged.
